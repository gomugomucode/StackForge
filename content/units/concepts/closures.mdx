# 1. Introduction & Real Production Problem Statement

## Why Closures Matter
A closure is the combination of a function bundled together with references to its surrounding lexical state. Understanding closures is critical for state encapsulation, middleware pipelines, and eliminating React stale closure bugs.

---

# 2. Core Concepts & Mental Model

## 1. Beginner Explanation
A closure gives an inner function access to variables defined in an outer function, even after the outer function execution context has finished.

```javascript
function outer() {
  const secret = "StackForge Atomic Unit";
  return function inner() {
    console.log(secret);
  };
}
const fn = outer();
fn(); // Logs: "StackForge Atomic Unit"
```

## 2. Senior Explanation & V8 Internals
V8 allocates closure variables onto the Heap inside a `Context` object bound to `JSFunction.[[Scope]]`.

# 5. Performance, Security & Interview Questions

## Performance Notes
Avoid allocating closures in high-frequency tight loops ($> 100,000$ iterations/sec).

## Interview Questions
### Q: How does V8 manage closure memory retention?
- *Answer*: V8 allocates captured variables onto the Heap in a `Context` object, preventing garbage collection until all enclosing function references are unlinked.
