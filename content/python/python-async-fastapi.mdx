# 1. Introduction

## Why Python AsyncIO & FastAPI Architecture Matter
Python has traditionally been single-threaded due to the **Global Interpreter Lock (GIL)**. However, modern asynchronous Python using `asyncio`, **ASGI (Asynchronous Server Gateway Interface)** web servers (Uvicorn), and **FastAPI** enables building non-blocking I/O microservices capable of handling tens of thousands of concurrent WebSocket connections and HTTP requests.

# 2. Core Concepts

## Python AsyncIO vs Threading vs Multiprocessing

```
+-------------------------------------------------------------------------+
| CONCURRENCY PARADIGM COMPARISON IN PYTHON                               |
|                                                                         |
| 1. AsyncIO (Cooperative Multitasking):                                  |
|    - Single-threaded event loop running coroutines via `async/await`.   |
|    - Best for I/O-bound tasks (Network calls, Database queries).       |
|                                                                         |
| 2. Threading (Preemptive Multitasking):                                 |
|    - Multiple OS threads constrained by the GIL.                        |
|    - Only 1 thread executes Python bytecode at any instant.             |
|                                                                         |
| 3. Multiprocessing:                                                     |
|    - Spawns separate OS processes with dedicated Python interpreters.  |
|    - Bypasses GIL; best for CPU-bound tasks (ML, Image Processing).     |
+-------------------------------------------------------------------------+
```

# 4. Interview Questions

### Easy Questions
1. **Q: What is the Python Global Interpreter Lock (GIL)?**
   - *Answer*: A mutex that allows only one thread to execute Python bytecode at a time, preventing true multi-threaded parallel CPU execution in CPython.
2. **Q: What is FastAPI?**
   - *Answer*: A high-performance Python web framework based on OpenAPI, Starlette, and Pydantic offering automatic type safety and interactive documentation.
3. **Q: What is the difference between WSGI and ASGI?**
   - *Answer*: WSGI (Web Server Gateway Interface) is synchronous and block-per-request; ASGI supports asynchronous I/O, WebSockets, and HTTP/2.
4. **Q: What does `async def` do in Python?**
   - *Answer*: Defines a coroutine function that can be paused and resumed using the `await` keyword within an event loop.
5. **Q: What is Pydantic in Python?**
   - *Answer*: A data parsing and validation library using Python type hints to enforce schema correctness at runtime.

### Medium Questions
6. **Q: How do you run CPU-bound tasks in FastAPI without blocking the AsyncIO event loop?**
   - *Answer*: Offload CPU-heavy computations to a background process pool using `loop.run_in_executor(executor, func)` or Celery worker queues.
7. **Q: Compare `asyncio.gather()` vs `asyncio.wait()`.**
   - *Answer*: `gather()` runs multiple coroutines concurrently and returns results in order; `wait()` gives fine-grained control over cancellation and partial completion status.
8. **Q: How does Dependency Injection work in FastAPI?**
   - *Answer*: Uses the `Depends()` function parameter to automatically resolve dependencies (DB sessions, authentication tokens) per request context.
9. **Q: What is `uvicorn` and `gunicorn` deployment pattern?**
   - *Answer*: Gunicorn acts as a process manager spawning multiple Uvicorn worker processes running ASGI event loops behind a reverse proxy (Nginx).
10. **Q: How do you handle database connections asynchronously in Python?**
    - *Answer*: Use async ORMs / drivers like `SQLAlchemy 2.0 async`, `asyncpg`, or `tortoise-orm` connected to connection pools.

### Advanced Questions
11. **Q: Walk through how the Python AsyncIO Event Loop schedules Coroutines, Futures, and Tasks.**
    - *Answer*: The loop monitors I/O file descriptors via `epoll`/`kqueue`, waking up suspended coroutines when I/O operations complete and scheduling their generator callbacks onto the execution queue.
12. **Q: How does Python 3.12+ Subinterpreters project address the GIL?**
    - *Answer*: Enables multiple independent Python interpreters within a single OS process, each having its own isolated GIL for true parallel CPU thread execution.
13. **Q: How do you prevent Memory Leaks in long-running Python AsyncIO services?**
    - *Answer*: Explicitly cancel orphaned tasks (`task.cancel()`), avoid keeping references to unawaited futures in global dicts, and monitor garbage collector generation stats.
14. **Q: Explain how Pydantic v2 leverages Rust for performance.**
    - *Answer*: Pydantic v2 rewrote its core validation engine (`pydantic-core`) in Rust, speeding up JSON parsing and schema validation by 5x-20x.
15. **Q: How do you implement Distributed Tracing in FastAPI with OpenTelemetry?**
    - *Answer*: Use `opentelemetry-instrumentation-fastapi` to automatically extract W3C `traceparent` headers, attach span context to request state, and export traces to OpenTelemetry collectors.
