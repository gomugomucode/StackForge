# 1. Introduction & Real Production Problem Statement

## Why Machine Learning Math Matters
Machine Learning (ML) transforms software engineering from explicit rule-based algorithms (`if/else`) into statistical models that learn parameters ($\mathbf{W}, b$) directly from data.

Understanding **Gradient Descent** and **Vector Matrix Multiplications** is mandatory for fine-tuning LLMs, building custom embedding search engines, and diagnosing neural network convergence failures.

# 2. Core Concepts & Mental Model

## 1. Linear Model & Loss Function
A linear model predicts target output $\hat{y}$ using weight parameters $\mathbf{w}$ and bias $b$:

$$\hat{y} = \mathbf{w}^T \mathbf{x} + b$$

The **Mean Squared Error (MSE) Loss Function** measures error across $N$ samples:

$$\mathcal{L}(\mathbf{w}, b) = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$

## 2. Gradient Descent Optimization
To minimize loss, parameter values are updated iteratively in the opposite direction of the loss gradient using learning rate $\eta$:

$$\mathbf{w} \leftarrow \mathbf{w} - \eta \nabla_{\mathbf{w}} \mathcal{L}$$

# 3. Code Examples & Production PyTorch Implementation

## Enterprise PyTorch Tensor Model Training

```python
import torch
import torch.nn as nn
import torch.optim as optim

# 1. Define simple Neural Network Classifier
class LinearClassifier(nn.Module):
    def __init__(self, input_dim: int, num_classes: int):
        super().__init__()
        self.linear = nn.Linear(input_dim, num_classes)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.linear(x)

# 2. Setup model, loss function, and Adam optimizer
model = LinearClassifier(input_dim=768, num_classes=2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 3. Dummy batch training loop
inputs = torch.randn(32, 768)
targets = torch.randint(0, 2, (32,))

optimizer.zero_grad()
outputs = model(inputs)
loss = criterion(outputs, targets)
loss.backward() # Backpropagation gradient computation
optimizer.step() # Parameter update step
print(f"Batch Training Loss: {loss.item():.4f}")
```

# 4. Debugging Guide & Common Mistakes

## Diagnosing Overfitting vs Underfitting

```
High Training Loss + High Validation Loss  ===> UNDERFITTING (Model too simple / Increase model capacity)
Low Training Loss  + High Validation Loss  ===> OVERFITTING  (Model memorized training data / Add Regularization)
Low Training Loss  + Low Validation Loss   ===> OPTIMAL FIT   (High Generalization Accuracy)
```

# 6. Interview Questions & Practice Exercises

### Q1: Explain the difference between L1 (Lasso) and L2 (Ridge) Regularization.
- *Answer*: L1 regularization adds absolute parameter weights ($|\mathbf{w}|$) driving weights to exact zeros (sparse feature selection); L2 adds squared parameter weights ($\mathbf{w}^2$) shrinking weights smoothly toward zero.

### Q2: What is the Vanishing Gradient problem in Deep Neural Networks?
- *Answer*: During backpropagation, repeated matrix multiplication of small gradients through deep layers causes gradients to shrink exponentially toward zero, halting parameter training in early layers (solved using ReLU activations and Residual Skip Connections).
